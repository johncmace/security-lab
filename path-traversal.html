Web security · OWASP A01 · CWE-22

Path traversal, X-rayed

A download link takes a filename and reads that file from a folder on the server. But if the app pastes your filename straight into a path, a few ../ steps walk out of that folder and into the rest of the filesystem — source code, config, credentials. Watch it escape, then add the one check that keeps it in bounds.

Vulnerable: the filename is joined to the folder and opened as-is.
