About this lab

Each explainer is a safe, self-contained simulation that runs entirely in your browser. No real database or server is involved, and all data is invented, so nothing here can be used to attack a live system. The aim is to make the mechanism and its impact visible, and to show the defensive fix alongside every attack.

To practise against a real target in a controlled environment, use purpose-built apps such as OWASP Juice Shop or PortSwigger's Web Security Academy.
